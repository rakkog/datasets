# Datasets
* This repo contains 3 different datasets: 12STI (12 Standard Test Images), BSD68 (Berkeley Segmentation Dataset), and medical
* There are 12 grayscale images with a resolution of 512x512 in the 12STI dataset
  <https://www.imageprocessingplace.com/root_files_V3/image_databases.htm>
* There are 68 grayscale images with resolutions of 321x481 and 481x321 in the BSD68 dataset
  <https://www2.eecs.berkeley.edu/Research/Projects/CS/vision/bsds/>
* There are 6 grayscale images with a resolution of 256x256 in the medical dataset
